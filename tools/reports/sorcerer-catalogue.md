# M20 Sorcerer catalogue (Phase 1)

`app/public/js/data-sorcerer.js` is generated by `tools/build_sorcerer_catalogue.py` from the
transcribed JSON in `tools/sorcerer-src/` (schema in `TRANSCRIPTION.md`). Source: *M20 Sorcerer*
(Paradox 2022). Page numbers are the printed book pages.

| Block | Count | Notes |
| --- | --- | --- |
| PATHS | 21 | Affiliations that list Herbalism resolve to Alchemy, and Shadowcasting to Shadows (p. 45) |
| Rituals | 67 incl. Store Spell on every Path that has rituals | Alchemy, Divination, Starlight, Summoning/Binding/Warding and Weather Control list no named rituals |
| PHENOMENA | 22 | five levels each |
| AFFILIATIONS | 20 + Unaligned + 3 Ascension War societies | favored Attributes/Paths resolved to ids (`favoredPathIds`) |
| MERITS_FLAWS | 17 | variable costs kept as printed with `costOptions` |
| ARTIFACTS | 12 | Tools of the Trade, pp. 108-110 |
| ASPECTS | 11 | Damage/Healing has rule text, no dot table |
| CORE_RULES | pathMagic, psychic | pp. 12-17 and p. 54, with sidebars |

Verification: every description, ritual, level entry, affiliation, merit and artifact text was
checked against the PDF's reading-order extraction (six-word windows at six points each);
372 of 379 passages matched at 5/6 or better, the remaining 7 are flattened tables.

Known book quirks kept as printed: "Summon, Binding, and Warding" (Aeon Rites), "Stamina +
Mediation" (Psychic Feedback), "Orinthomancy" (Divination sidebar). Affiliations that list
"Shadow" among Paths are mapped to the Shadows Path.
